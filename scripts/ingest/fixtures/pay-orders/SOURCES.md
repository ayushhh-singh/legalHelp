# Fixtures for `test_pay_orders.py`

Six small text files. Five are `pdfplumber`-extracted text from real Department of
Expenditure PDFs, fetched once by hand for this session and stored as extracted
text only — never the PDF itself, the same "cite, don't archive" line
`scripts/authoring/sources/` draws for a different pipeline. The sixth is
explicitly synthetic and says so in its own header line.

Two of the five real fixtures (`da-order-current.txt`, `da-order-previous.txt`) are
literally empty files — both scans, per CLAUDE.md's own note that "every DoE order
is a scan, read by rendering and recognising and then checking by eye." That is
the true, common case this whole script is built around, which is why
`check_da_order` treats "no usable text" as a **manual-review** outcome rather
than an error: see `docs/MAINTENANCE.md`.
